## 5. 已知限制与未验证项（诚实声明）

1. **WebDAV 无真实服务器**：三方比对/冲突副本为纯函数单测；PROPFIND/PUT/MKCOL 未对真实服务端验证；删除同步未实现（v1 只做新增/修改收敛，宁可复活不丢数据）。
2. **性能验收未达正式口径**：AC-024~027 需 10,000 篇 / 2GB 基准数据集，本轮 1,000 篇冒烟仅作趋势参考。
3. **PDF 导出依赖 WebView 打印管线**（设计 DD-6），未自动化验证打印排版。
4. **跨平台未实测**：仅在 Windows 构建/运行；macOS/Linux 代码路径未验证。
5. **部分交互未端到端走查**：图片粘贴、`[[` 补全弹层、大纲滚动、命令面板执行、200% 缩放、纯键盘闭环、可用性测试（AC-029）等，已在 AC 矩阵标 ⬜/🟡。
6. **更新检查服务器为占位地址**：无真实官方 manifest，节流/失败路径已单测。
