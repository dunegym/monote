## 核心设计决策（速览）

- **本地优先**：数据为标准 UTF-8 `.md` + YAML front-matter，无格式锁定，卸载不丢数据；
- **知识组织**：`[[双链]]` + 反向链接面板 + 标签聚合；
- **快速检索**：SQLite FTS5 全文索引，1 万篇基准集标题检索 ≤ 100 ms / 全文 ≤ 500 ms（P95）；
- **同步策略**：官方云服务范围外，采用用户自备 WebDAV，冲突"新者为准 + 冲突副本"，任何一版不静默丢弃；
- **可靠性**：停顿 2 s 自动保存，异常退出丢失上界 10 s，每日自动备份保留 5 份。
