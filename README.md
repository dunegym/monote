## 核心设计决策（速览）

- **本地优先**：数据为标准 UTF-8 `.md` + YAML front-matter，无格式锁定，卸载不丢数据；
- **知识组织**：`[[双链]]` + 反向链接面板 + 标签聚合；
- **快速检索**：SQLite FTS5 全文索引，1 万篇基准集标题检索 ≤ 100 ms / 全文 ≤ 500 ms（P95）；
- **同步策略**：官方云服务范围外，采用用户自备 WebDAV，冲突"新者为准 + 冲突副本"，任何一版不静默丢弃；
- **可靠性**：停顿 2 s 自动保存，异常退出丢失上界 10 s，每日自动备份保留 5 份。

## 应用实现（MoNote 桌面版）

本仓库同时包含按上述需求与《软件设计文档》（`../exp02/docs/01-软件设计文档.md`）实现的桌面应用源码，
位于 [`app/`](app/README.md)：

- **技术栈**：Tauri 2（Rust 核心 + 系统 WebView2），前端为原生 HTML/CSS/ES Module（离线 vendor：marked / KaTeX / highlight.js）；
- **已实现**：Markdown 编辑与实时预览、双链/反链/标签、SQLite FTS5 中文检索、回收站、自动备份、导入导出、WebDAV 同步、命令面板、快捷键自定义、通知中心、亮/暗主题；
- **质量**：`cargo test` 153 项自动化测试全绿（141 单元 + 11 集成 + 1 性能冒烟）；release 可执行文件 8.25 MB，空闲内存约 40 MB；
- **文档**：[应用 README](app/README.md)、[实现说明](app/docs/实现说明.md)、[测试报告](app/docs/测试报告.md)、[开发合同](app/CONTRACT.md)。

构建与运行（Windows，需 Rust + MSVC）：

```powershell
cd app\src-tauri
cmd /c "call E:\IDE\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build\vcvars64.bat >nul && cargo run"
```
